# Solomon voice

Live voice chat with Solomon, Elisha's assistant: a Vapi web call to the same assistant and brain as his phone line.
Served by GitHub Pages at https://solomon-1.github.io/solomon-voice/ because the claude.ai artifact frame blocks the mic.

No keys live here. The Agent Tower opens the page with its settings in the URL hash, and the page keeps them in the
browser. Source of truth: `apps-script/AgentInbox/jarvis-voice.html` in Solomon-1/elisha-os.
